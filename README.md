# یار همراه

نمونهٔ اولیهٔ اندروید برای انتخاب آگاهانهٔ مخاطب، دریافت پیش‌نمایش پیامک از اعلان‌ها، انتخاب فایل و اشتراک‌گذاری دستی با برنامه‌های دیگر.

## ساخت APK
GitHub Actions با هر push به شاخهٔ main، نسخهٔ debug را می‌سازد. از بخش Actions وارد اجرای موفق شوید و artifact با نام `YarHamrah-debug-apk` را دریافت کنید.

## نصب و مجوزها
- مخاطبین: فقط پس از زدن دکمهٔ «انتخاب مخاطب» درخواست می‌شود.
- اعلان‌ها: برای دیدن پیش‌نمایش پیامک‌های جدید باید کاربر از تنظیمات اندروید، دسترسی Notification Access را برای یار همراه فعال کند.
- فایل‌ها: از انتخاب‌گر رسمی اندروید استفاده می‌شود؛ دسترسی کلی به حافظه درخواست نمی‌شود.
- ارسال داده: هیچ داده‌ای خودکار به اینترنت فرستاده نمی‌شود؛ اشتراک‌گذاری فقط با اقدام صریح کاربر انجام می‌شود.

## محدودیت مهم پیامک
این نمونه تاریخچهٔ کامل SMS را نمی‌خواند. فقط متن موجود در اعلان‌های جدید را می‌تواند نشان دهد و اگر برنامهٔ پیامک پیش‌نمایش متن را مخفی کرده باشد، متن در دسترس نیست. برای خواندن مستقیم SMS لازم است برنامه نقش پیش‌فرض SMS را بگیرد و الزامات سیاست‌های اندروید/Google Play رعایت شود.

این پروژه نمونهٔ آزمایشی است، نه نسخهٔ تأییدشدهٔ انتشار عمومی. قبل از استفادهٔ واقعی، روی دستگاه خود تست کنید.
